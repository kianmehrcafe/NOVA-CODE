Tiny challenges 🎯

Don't just read code. Change it. These challenges are designed to be quick.

Challenge 01 EASY

Make the text blue

Use CSS to change the paragraph's text color to blue.

color: blue;
Challenge 02 EASY

Make a big heading

Change the heading size so it becomes 40 pixels tall.

font-size: 40px;
Challenge 03 EASY

Round the box

Use border-radius to turn a sharp box into a rounded one.

border-radius: 20px;
Challenge 04 EASY

Add a button click

Use JavaScript to change the button text when the button gets clicked.

button.onclick = ...
Challenge 05 MEDIUM

Center the card

Use flexbox to center something both horizontally and vertically.

display: flex; justify-content: center; align-items: center;
Challenge 06 MEDIUM

Make something move

Add a CSS transition so a button smoothly changes when you hover it.

transition: .3s;
